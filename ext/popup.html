Пошаговое руководство
1
Получите TMDB API Key
Зарегистрируйтесь на themoviedb.org, перейдите в Настройки ➔ API и создайте бесплатный ключ разработчика (Developer Key v3).
Открыть TMDB API ↗
2
Авторизуйтесь через TMDB
Вставьте ключ во вкладке «Ключи», нажмите «Войти», разрешите доступ во всплывающем окне и нажмите «Подтвердить».
3
Сканируйте свой Кинопоиск
Откройте вкладку со своим профилем на kinopoisk.ru и нажмите «1. Сканировать КП». Можно переключаться на другие аккаунты параллельно.
4
Переносите в TMDB без дублей
Нажмите «2. В TMDB». Расширение автоматически проверит ваш аккаунт и пропустит фильмы, где уже стоят оценки!
5
Экспорт таблиц CSV
Во вкладке «Экспорт CSV» скачивайте готовые таблицы с ID, названиями, годами, оценками и прямыми ссылками на КП.
