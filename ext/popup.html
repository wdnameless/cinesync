IMDb ● OK
Экспорт в формате IMDb CSV. Позволяет сохранить данные в стандартной схеме IMDb.
Импорт в IMDb невозможен: сервис не предоставляет механизмов импорта или загрузки списков пользователями.
Включить как цель синхронизации
MovieLens ● OK
Экспорт датасета в формате MovieLens ratings.csv (userId, movieId, rating, timestamp).
Импорт в MovieLens не поддерживается: это формат датасета для исследований, импорт пользователем не предусмотрен.
Включить как цель синхронизации
Источник: Кинопоиск ● OK
Кинопоиск — источник данных. У него нет API на запись, поэтому он не может быть получателем синхронизации.
Пошаговое руководство
1
Получите TMDB API Key
Зарегистрируйтесь на themoviedb.org, перейдите в Настройки ➔ API и создайте бесплатный ключ разработчика (Developer Key v3).
Открыть TMDB API ↗
2
Авторизуйтесь через TMDB
Вставьте ключ во вкладке «Ключи», нажмите «Войти», разрешите доступ во всплывающем окне и нажмите «Подтвердить».
3
Сканируйте свой Кинопоиск
Откройте вкладку со своим профилем на kinopoisk.ru и нажмите «1. Сканировать КП». Можно переключаться на другие аккаунты параллельно.
4
Переносите в TMDB без дублей
Нажмите «2. В TMDB». Расширение автоматически проверит ваш аккаунт и пропустит фильмы, где уже стоят оценки!
5
Экспорт таблиц CSV
Во вкладке «Экспорт CSV» скачивайте готовые таблицы с ID, названиями, годами, оценками и прямыми ссылками на КП.
6
Выберите получателей синхронизации
На вкладке «Ключи» включите нужные сервисы переключателем и сохраните их ключи. Затем нажмите «2. Синхронизировать».
7
Импорт в Letterboxd, IMDb, MovieLens
Для Letterboxd скачайте CSV и загрузите на официальной странице импорта. В IMDb и MovieLens импорт отсутствует — доступен только экспорт данных.
Открыть импорт Letterboxd ↗
