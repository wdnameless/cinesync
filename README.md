# 🎬 CineSync — Movie Ratings & Watchlist Sync

> Перенос ваших оценок и списка «Буду смотреть» между киносервисами.
>
> CineSync читает данные из Кинопоиска и раскладывает их в **TMDB** и **Simkl** через API,
> пишет напрямую в ваш профиль **Кинопоиска**, а для **Letterboxd**, **IMDb** и **MovieLens**
> формирует готовые CSV-таблицы точного формата. Один прогон — все платформы сразу.

Доступно в двух вариантах:
1. **Расширение для браузера (Chrome / Chromium)** — современный интерфейс, визуальное управление, параллельные задачи, умный пропуск дубликатов, переключатель RU/EN.
2. **CLI / TUI скрипт (Python)** — консольное приложение и скрипты автоматизации на Playwright.

---

## 🚀 Вариант 1: Расширение Chrome (Рекомендуется)

Папка `ext/` содержит готовое расширение Manifest V3.

### Куда переносятся данные

| Сервис | Режим | Авторизация |
|---|---|---|
| **TMDB** | API | API Key v3 + сессия (кнопка «Войти» → подтверждение на themoviedb.org) |
| **Simkl** | API | Client ID приложения + PIN-код на simkl.com/pin |
| **Кинопоиск** | автоматизация вкладки | ваша открытая сессия Кинопоиска |
| **Letterboxd** | CSV | импорт вручную на letterboxd.com/import/ |
| **IMDb** | только экспорт | у IMDb нет импорта списков |
| **MovieLens** | только экспорт | у MovieLens нет импорта пользовательских файлов |

Кинопоиск — **источник**, а не получатель. Trakt поддержки не имеет.

### Возможности
- **Сбор оценок и списка отложенного** («Буду смотреть») напрямую из активной сессии Кинопоиска.
- **Прямой перенос в TMDB и Simkl**: автоматический поиск фильмов/сериалов с проверкой типа медиа, года выпуска и совпадения названия (включая букву «ё» и франшизные подназвания). Кандидат принимается только при уверенном совпадении — сомнительные пары пропускаются как ошибки, а не пишутся на чужой фильм.
- **Умный пропуск дубликатов**: расширение сверяет оценки и Watchlist с профилем получателя и не перезаписывает уже существующие.
- **Обогащение через Kinopoisk Unofficial API**: подтягивает IMDb ID и оригинальное название, что заметно повышает точность сопоставления.
- **Контроль процесса**: стоп, пауза и возобновление; при обнаружении капчи сбор останавливается и ждёт, пока вы её пройдёте.
- **Экспорт в CSV**: готовые файлы для Letterboxd (с разбивкой по 1 МБ), IMDb (13 колонок) и MovieLens (`userId,movieId,rating,timestamp`), UTF-8 с BOM.
- **Живой пинг ключей** с индикатором валидности (`VALID` / `INVALID`).
- **Двуязычный интерфейс** (RU / EN).

### Сборка и установка
```bash
cd ext
npm install
npm run build      # typecheck + сборка в dist/
npm test           # тесты адаптеров
npm run package    # соберёт cinesync-<версия>.zip для стора
```
1. Откройте `chrome://extensions/` и включите **Режим разработчика**.
2. **Загрузить распакованное расширение** → выберите папку `ext/`.
3. Закрепите иконку и откройте попап.

### Настройка получателей
1. Вкладка **Ключи** → выберите сервис.
2. **TMDB**: вставьте API Key v3, нажмите «Сохранить», затем «Войти» и подтвердите доступ на themoviedb.org, после чего «Подтвердить».
3. **Simkl**: вставьте Client ID приложения, нажмите «Сохранить», затем «Подключить» — код скопируется, откроется simkl.com/pin; введите код и нажмите ОК в диалоге.
4. Включите тумблер «Участвует в синхронизации» у нужных сервисов.

> Для Simkl нужен ваш собственный Client ID: у сервиса нет публичного клиента, который можно было бы безопасно встроить.

### Вкладка «Настройки»: Kinopoisk Unofficial API

Ключ **Kinopoisk Unofficial** (получить на [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech/)) включает обогащение: расширение подтягивает IMDb ID и оригинальное название по Kinopoisk ID. Это заметно повышает точность сопоставления, особенно для русских названий и сериалов. Без ключа всё работает, но часть фильмов может не сопоставиться.

Это **другой** сервис, чем `KINOPOISK_DEV_TOKEN` в Python-скриптах, — ключи не взаимозаменяемы.

## 🐍 Вариант 2: Python CLI & TUI

### Установка зависимостей
```bash
pip install -r requirements.txt
python -m playwright install chromium
```

### Настройка `.env`
Скопируйте пример конфигурации и укажите ваши ключи:
```bash
cp .env.example .env
```
- `TMDB_API_KEY`: v3 API Key с [themoviedb.org/settings/api](https://www.themoviedb.org/settings/api).
- `KINOPOISK_DEV_TOKEN`: бесплатный токен от бота [@kinopoiskdev_bot](https://t.me/kinopoiskdev_bot) (для обогащения метаданных и IMDb ID).

### Запуск интерактивного меню (TUI)
```bash
python tui.py
```
- **Экспорт Кинопоиск**: вход в аккаунт через окно браузера и выгрузка истории.
- **Маппинг**: сопоставление Kinopoisk ID с TMDB ID с локальным сохранением чекпоинтов.
- **Логин в TMDB**: авторизация аккаунта через браузер (сохранение сессии).
- **Заливка**: перенос оценок и списков в аккаунт TMDB.

## 🔒 Безопасность и конфиденциальность
- Все API-ключи, токены сессий и экспортированные данные хранятся **исключительно локально** на вашем компьютере (`chrome.storage.local` или локальный `.env`).
- Никакие пароли или токены не передаются сторонним серверам.
