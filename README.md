# 🎬 Kinopoisk to TMDB & CSV Migrator

> Инструмент для полного переноса пользовательских оценок и списка «Буду смотреть» (Watchlist) с **Кинопоиска** в **The Movie Database (TMDB)**, а также резервного экспорта в чистые **CSV-таблицы**.

Доступно в двух вариантах:
1. **Расширение для браузера (Chrome / Chromium)** — современный интерфейс, визуальное управление, параллельные задачи, умный пропуск дубликатов, переключатель RU/EN.
2. **CLI / TUI скрипт (Python)** — консольное приложение и скрипты автоматизации на Playwright.

---

## 🚀 Вариант 1: Расширение Chrome (Рекомендуется)

Папка `ext/` содержит готовое расширение Manifest V3.

### Возможности
- **Сбор оценок и списка отложенного** («Буду смотреть») напрямую из активной сессии Кинопоиска.
- **Прямой перенос в TMDB**: автоматический поиск фильмов/сериалов, проверка соответствия названий (включая учет буквы «ё» и франшизных подназваний) и выставление пользовательских оценок.
- **Умный пропуск дубликатов**: расширение автоматически сверяет оценки с вашим профилем TMDB — если фильм уже оценен или добавлен в Watchlist, он не перезаписывается.
- **Параллельная работа**: сканирование Кинопоиска и синхронизация в TMDB работают в независимых потоках, позволяя параллельно собирать данные для других аккаунтов.
- **Экспорт в CSV**:
  - `⭐ Оценки пользователей` (Kinopoisk ID, Название, Год, Оценка, Ссылка).
  - `📑 Буду смотреть / Watchlist` (Kinopoisk ID, Название, Год, Ссылка).
  - `💾 Полный архив базы` (все категории, типы медиа и метаданные).
  - Формат полностью совместим с Excel / Таблицами (UTF-8 BOM, разделитель `;`).
- **Интерактивная вкладка «Инструкция»** с подробным пошаговым руководством и кнопками для прямого перехода к настройкам API.
- **Живой пинг ключей** с индикатором валидности (`VALID` / `INVALID`).
- **Двуязычный интерфейс** (RU / EN).

### Установка расширения
1. Перейдите в папку `ext/` и соберите проект (при необходимости):
   ```bash
   cd ext
   npm install
   npm run build
   ```
2. Откройте в браузере страницу управления расширениями: `chrome://extensions/`
3. Включите **Режим разработчика** (Developer mode) в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** (Load unpacked) и выберите папку `ext/dist` (или `ext/`).
5. Закрепите иконку расширения и откройте попап.

## 🐍 Вариант 2: Python CLI & TUI

### Установка зависимостей
```bash
pip install -r requirements.txt
python -m playwright install chromium
```

### Настройка `.env`
Скопируйте пример конфигурации и укажите ваши ключи:
```bash
cp .env.example .env
```
- `TMDB_API_KEY`: v3 API Key с [themoviedb.org/settings/api](https://www.themoviedb.org/settings/api).
- `KINOPOISK_DEV_TOKEN`: бесплатный токен от бота [@kinopoiskdev_bot](https://t.me/kinopoiskdev_bot) (для обогащения метаданных и IMDb ID).

### Запуск интерактивного меню (TUI)
```bash
python tui.py
```
- **Экспорт Кинопоиск**: вход в аккаунт через окно браузера и выгрузка истории.
- **Маппинг**: сопоставление Kinopoisk ID с TMDB ID с локальным сохранением чекпоинтов.
- **Логин в TMDB**: авторизация аккаунта через браузер (сохранение сессии).
- **Заливка**: перенос оценок и списков в аккаунт TMDB.

## 🔒 Безопасность и конфиденциальность
- Все API-ключи, токены сессий и экспортированные данные хранятся **исключительно локально** на вашем компьютере (`chrome.storage.local` или локальный `.env`).
- Никакие пароли или токены не передаются сторонним серверам.
